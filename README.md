## Үнэлгээний дүрэм

| Оноо | Үсгэн үнэлгээ |
|---:|:---:|
| 90–100 | A |
| 80–89.99 | B |
| 70–79.99 | C |
| 60–69.99 | D |
| 0–59.99 | F |

Нийлбэр онооны бүрэлдэхүүн: ирц 10, лаборатори 40, сорил 1 — 10, сорил 2 — 10, эцсийн шалгалт 30. Бүрэлдэхүүн бүр өөрийн зөвшөөрөгдөх мужид байх ёстой.

## Тестийн хамрах хүрээ

- Наад захын болон дээд хязгаар: 0, 100.
- Үнэлгээний зааг: 90, 89.99, 60, 59.99.
- Сөрөг, 100-аас их, NaN болон хязгааргүй утга.
- `totalScore`-ийн зөв нийлбэр болон буруу бүрэлдэхүүн.
- Хоёр `@ParameterizedTest`: `letterGrade` болон `totalScore`.
- Тестийн аргууд AAA (Arrange–Act–Assert) дараалал, `@DisplayName` ашиглана.

## Ажиллуулах

Java 17 шаардлагатай. Өөрийн орчинд хувилбар шалгах:

```bash
java -version
mvn -version
cd lab04-resubmission
mvn clean test
```

## Мутацийн туршилт

CI нь `GradeCalculator` доторх `score >= 90.0` нөхцөлийг түр `score > 90.0` болгон өөрчилж тест ажиллуулна. 90 онооны заагийн тест мутацийг илрүүлж унах ёстой. Дараа нь эх кодыг автоматаар анхны `>= 90.0` нөхцөлд сэргээж `mvn clean test` дахин ажиллуулна. Хоёр туршилтын бодит Maven гаралт GitHub Actions-аас `results/` хавтаст хадгалагдана.
