## Үнэлгээний дүрэм

| Оноо | Үсгэн үнэлгээ |
|---:|:---:|
| 90–100 | A |
| 80–89.99 | B |
| 70–79.99 | C |
| 60–69.99 | D |
| 0–59.99 | F |

Нийлбэр онооны бүрэлдэхүүн: ирц 10, лаборатори 40, сорил 1 — 10, сорил 2 — 10, эцсийн шалгалт 30. Аль нэг утга өөрийн зөвшөөрөгдөх мужийг зөрчсөн эсвэл төгсгөлөг тоо биш бол `IllegalArgumentException` үүсгэнэ.

## Тестийн хамрах хүрээ

- Энгийн жишээ болон A/F үнэлгээ.
- Хязгаарын утгууд: 90, 89.99, 60, 59.99, 0, 100.
- Буруу оролт: сөрөг оноо, 100-аас их оноо, NaN, хязгааргүй утга.
- Нийлбэр онооны дээд болон ердийн утгууд.
- Нийлбэр онооны буруу бүрэлдэхүүн.
- Хоёр `@ParameterizedTest`, `@CsvSource`.
- Тестүүдэд AAA (Arrange–Act–Assert) бүтэц болон Монгол `@DisplayName` ашигласан.

## Орчны мэдээллийг бүртгэх

PowerShell дээр төслийн хавтас руу орж дараах командыг ажиллуул:

```powershell
java -version
mvn -version
```

Гарсан хувилбаруудыг өөрийн бодит орчны мэдээллээр энэ README-д бичнэ. Урьдчилан таамагласан хувилбар оруулахгүй.

## Тест ажиллуулах

```powershell
mvn clean test
```

Амжилттай бол Maven `BUILD SUCCESS` харуулна. Бодит тестийн тоо, амжилтгүй/алдаатай тестийн тоог Maven-ийн гаралтаас авч тэмдэглэнэ.

## Мутацийн туршилт

1. `GradeCalculator.java` доторх `score >= 90.0` нөхцөлийг түр хугацаанд `score > 90.0` болгон өөрчил.
2. `mvn clean test` ажиллуул. 90 онооны заагийг шалгасан тест унах ёстой.
3. Нөхцөлийг анхны `>= 90.0` хэлбэрт буцаа.
4. `mvn clean test` дахин ажиллуулж бүх тест амжилттай болсныг баталгаажуул.

Мутацийн туршилтын дараа эх код заавал зөв хувилбартаа буцсан эсэхийг шалга. Туршилтын гаралтыг бодитоор авсны дараа хадгалж, README-д тайлбарлана.
