# Лаборатори №4

Төслийн үндсэн тайлбар, оюутны мэдээлэл, туршилтын үр дүн болон мутацийн туршилтын дүгнэлтийг репозиторийн үндсэн [README.md](../README.md) файлаас үзнэ үү.

Maven төслийг энэ хавтаснаас ажиллуулна:

```bash
mvn clean test
```

Тестийн бодит гаралт репозиторийн үндсэн `results/mvn-test.txt` болон `results/mvn-test-mutant.txt` файлуудад хадгалагдана. `target/` нь build output тул Git-д commit хийхгүй.
