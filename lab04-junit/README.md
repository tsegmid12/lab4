## Мутацийн тест
- **Хийсэн өөрчлөлт:** `GradeCalculator.java` файлын `score >= 90` нөхцөлийг `score > 90` болгож өөрчилсөн.
- **Үр дүн:** `results/mvn-test-mutant.txt` файл дотор `testNinetyIsA` болон `letterGradeBoundaries` (90 онооны тохиолдол) тестүүд унасан (Failures: 2, BUILD FAILURE).
- **Дүгнэлт:** Энэ нь миний бичсэн тестүүд хязгаар утгыг (boundary value) зөв шалгаж байгааг баталж байна. Хэрэв тестүүд унахгүй байсан бол 90 оноог A гэж тооцож байгаа эсэхийг шалгах тест дутуу байсан гэсэн үг.

## Сонирхолтой алдаа/тест
Хамгийн сонирхолтой нь хязгаар утгын тестүүд байлаа. Ялангуяа 89.99 ба 90 онооны ялгааг шалгах тестүүд нь логик алдааг илрүүлэхэд хамгийн чухал үүрэг гүйцэтгэдэг. Parameterized тест ашигласнаар олон төрлийн оролтыг цөөн кодоор үр дүнтэй шалгаж чадсан.
